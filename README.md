# 🌊 Monitorização de Reservatório de Água

Um sistema de terminal desenvolvido em Python para simular a monitorização dos níveis de água de um reservatório, utilizando cores dinâmicas para classificar a gravidade de cada alerta.

## 🚀 Sobre o Projeto
Projeto desenvolvido para a **Agenda 11** da disciplina de Desenvolvimento de Sistemas de Informação (DSI) do curso técnico de Ciência de Dados. O objetivo principal é aplicar técnicas de programação estruturada (listas e laços de repetição) e explorar a formatação visual no terminal.

## ✨ Funcionalidades
* **Simulação Automatizada:** Avalia e imprime o estado dos cinco níveis do reservatório de forma contínua.
* **Alertas Visuais:** Mapeamento de cores progressivo (Vermelho, Amarelo, Verde, Ciano e Azul) com base na situação da água.
* **Saída Limpa:** Restauro automático do estilo padrão do terminal ao finalizar as mensagens, evitando que as cores afetem outras execuções no ecrã.

## 🛠️ Tecnologias Utilizadas
* **Python 3**
* **Colorama:** Biblioteca externa utilizada para renderizar os códigos ANSI de cor no terminal do Windows e de outros sistemas operativos.
